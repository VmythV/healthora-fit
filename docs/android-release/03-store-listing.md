### 完整描述（4000 字以内）

```
Healthora Fit 是一款专为健康管理设计的智能应用，帮助您轻松追踪饮食、运动和体重变化。

🥗 智能饮食记录
• AI 拍照识别 - 拍照即可自动识别食物和营养成分
• 详细营养追踪 - 卡路里、蛋白质、碳水化合物、脂肪
• 餐次分类管理 - 早餐、午餐、晚餐、加餐
• 手动编辑功能 - 自定义食物和份量

🏃 运动记录
• 多种运动类型 - 跑步、步行、骑行、游泳、力量训练等
• 智能卡路里估算 - 根据运动类型和时长自动计算
• 运动数据分析 - 趋势图表和统计

⚖️ 体重管理
• 体重趋势追踪 - 直观的折线图展示
• 目标设定 - 设置理想体重目标
• 进度可视化 - 清晰的进度指示

📊 数据分析
• 多维度统计 - 日/周/月/年数据分析
• 可视化图表 - 折线图、柱状图、饼图
• 营养分析 - 蛋白质、碳水、脂肪比例
• 运动分析 - 运动时长和消耗

📅 日历视图
• 月视图概览 - 快速查看记录情况
• 日视图详情 - 详细的时间线展示
• 智能标记 - 标记有记录的日期

🔒 隐私与安全
• 本地存储 - 所有数据存储在设备本地
• 无需注册 - 开箱即用，无需账号
• 数据导出 - 支持 JSON 格式导出备份
• Health Connect - 支持与健康平台数据同步

✨ 特色功能
• AI 食物识别 - 拍照即可识别食物营养成分
• 多语言支持 - 支持中文和英文
• 离线使用 - 无需网络即可记录数据
• 数据导入导出 - 方便的数据备份和恢复

Healthora Fit 是您管理健康生活的好帮手。开始记录，开启健康之旅！
```

## 📝 备注

### 关于"AI"功能说明

应用使用 AI 进行食物识别，需要在描述中说明：

- AI 用于食物图像识别
- 需要用户配置 API
- 数据仅在本地处理

### 关于 Health Connect 权限

如果应用请求健康数据权限，需要在描述中说明用途：

- 用于同步体重数据
- 用于同步运动数据
- 用户可选择是否启用
