# 隐私政策

**最后更新日期：2026 年 6 月 4 日**

---

## 概述

Healthora Fit（以下简称"本应用"）非常重视用户的隐私保护。本隐私政策旨在帮助您了解我们如何收集、使用和保护您的个人信息。

**重要提示：** 本应用所有数据均存储在您的设备本地，我们不会收集、存储或传输您的任何个人数据到外部服务器。

---

## 1. 数据收集

### 1.1 我们收集的数据

本应用在您的设备本地存储以下数据：

- **饮食记录**：食物名称、份量、营养成分、用餐时间
- **运动记录**：运动类型、时长、消耗卡路里、运动时间
- **体重记录**：体重数据、记录时间
- **目标设置**：目标体重、卡路里目标
- **AI 配置**：API 地址和密钥（仅存储在本地）

### 1.2 数据存储位置

所有数据均存储在您设备的本地数据库中（SQLite）。数据不会上传到任何外部服务器。

### 1.3 不收集的数据

我们**不收集**以下数据：

- ❌ 个人身份信息（姓名、邮箱、电话等）
- ❌ 位置信息
- ❌ 设备标识符
- ❌ 使用行为数据
- ❌ 崩溃报告
- ❌ 分析数据

---

## 2. 权限使用

### 2.1 相机权限

**用途：** 用于拍摄食物照片进行 AI 营养识别

**使用场景：**

- 用户主动使用拍照功能记录饮食时

**数据处理：**

- 照片仅在本地处理
- 照片可选择保存到相册
- 不会上传到任何服务器

### 2.2 存储权限

**用途：** 用于保存和读取应用数据

**使用场景：**

- 保存饮食照片
- 导出/导入数据备份

**数据处理：**

- 仅访问应用自身数据
- 不访问其他应用数据

### 2.3 健康数据权限（可选）

**用途：** 用于与 Health Connect / HealthKit 同步数据

**使用场景：**

- 同步体重数据
- 同步运动数据

**数据处理：**

- 仅在用户授权后使用
- 数据仅在本地同步
- 用户可随时撤销授权

---

## 3. AI 功能说明

### 3.1 AI 食物识别

本应用提供 AI 食物识别功能，用于识别食物和估算营养成分。

**工作原理：**

1. 用户拍摄食物照片
2. 照片在设备上转换为 Base64 编码
3. 照片数据发送到用户配置的 AI API 端点
4. AI 返回识别结果
5. 结果存储在本地数据库

**重要说明：**

- AI API 由用户自行配置（如 OpenAI、本地模型等）
- 照片数据会发送到用户指定的 API 端点
- 我们不控制第三方 AI 服务的数据处理方式
- 建议用户了解所使用 AI 服务的隐私政策

### 3.2 本地 AI 选项

用户可以选择使用本地 AI 模型：

- 配置本地 API 端点（如 Ollama）
- 照片数据不会离开设备
- 提供更高的隐私保护

---

## 4. 数据安全

### 4.1 数据存储安全

- 数据存储在设备本地 SQLite 数据库
- 数据库文件受操作系统保护
- 不需要网络连接即可使用

### 4.2 数据传输安全

- AI API 调用使用 HTTPS 加密
- 数据导出文件存储在设备本地
- 不向任何服务器传输用户数据

### 4.3 数据备份

- 用户可手动导出数据为 JSON 文件
- 导出文件存储在设备本地
- 用户自行管理备份文件

---

## 5. 第三方服务

### 5.1 AI API 服务

如果用户配置了第三方 AI API（如 OpenAI）：

- 照片数据会发送到该 API 端点
- 我们不控制第三方服务的数据处理
- 建议用户阅读第三方服务的隐私政策

### 5.2 Health Connect / HealthKit

如果用户授权连接健康平台：

- 数据在本地与健康平台同步
- 遵守平台的数据安全规范
- 用户可随时撤销授权

---

## 6. 用户权利

### 6.1 数据访问

- 用户可随时查看所有本地数据
- 数据存储在设备上，完全由用户控制

### 6.2 数据删除

用户可删除以下数据：

- 删除单条饮食/运动/体重记录
- 删除所有应用数据（通过应用设置）
- 卸载应用（删除所有数据）

### 6.3 数据导出

用户可导出所有数据：

- 格式：JSON
- 包含所有记录数据
- 存储在设备本地

### 6.4 权限管理

用户可管理应用权限：

- 在系统设置中撤销权限
- 权限撤销后功能可能受限

---

## 7. 儿童隐私

本应用不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。如果您是家长或监护人，发现您的孩子向我们提供了个人信息，请联系我们，我们将尽快删除相关信息。
