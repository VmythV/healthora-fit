# 迭代开发 SKILL

> **用途**：执行一次完整的迭代开发流程
> **触发方式**：`/iterate` 或 `/iterate [需求描述]`

---

## 执行流程

### 1. 获取当前日期

```bash
date +%Y-%m-%d
```

### 2. 查看 TODOLIST

读取 `docs/todolist.md`，了解：
- 当前进度（哪些 Phase 已完成）
- 下一个待开发的任务
- 任务优先级

### 3. 确定本次迭代任务

**如果有参数（用户提供的需求）**：
- 读取参数内容
- 查看相关设计文档（`docs/design.md`, `docs/architecture.md`, `docs/database.md`）
- 规划实现方案
- 与用户确认

**如果没有参数**：
- 根据 TODOLIST 确定下一个任务
- 与用户确认是否执行

### 4. 与用户确认

向用户展示：
- 本次迭代目标
- 具体任务列表
- 预计完成内容

等待用户确认后开始执行。

### 5. 执行开发

按照确认的任务列表：
1. 编写代码
2. 确保代码可运行
3. 处理可能的错误

### 6. 更新 TODOLIST

编辑 `docs/todolist.md`：
- 将完成的任务标记为 ✅
- 更新 Phase 状态
- 更新进度跟踪表

### 7. 记录开发进度

读取或创建进度文件：`docs/progress/YYYY-MM-DD.md`

**如果文件不存在**：
- 创建新文件
- 写入日期标题和完成内容

**如果文件已存在**：
- 追加本次迭代的完成内容

### 8. Git 提交

```bash
git add -A
git commit -m "feat: [本次迭代的简短描述]

- 完成的具体功能1
- 完成的具体功能2
- ..."
```

### 9. 告知用户

向用户报告：
- ✅ 本次迭代完成
- 📁 新增/修改的文件
- 📊 当前整体进度
- 🚀 下一步建议

---

## 示例输出格式

```
## ✅ 迭代完成

**日期**：2026-06-03
**任务**：Phase 2 - 数据库初始化模块

### 完成内容
- 创建 database/index.ts（数据库初始化）
- 创建 database/schema.ts（表结构定义）
- 创建 database/migrations.ts（迁移机制）

### 修改文件
- docs/todolist.md（更新进度）
- docs/progress/2026-06-03.md（记录日志）

### Git 提交
- commit: abc1234
- message: feat: 完成数据库初始化模块

### 当前进度
Phase 1: ✅ 已完成
Phase 2: 🔵 进行中 (2/5)

### 下一步
- 开发数据库查询函数（database/queries/）
```

---

## 注意事项

1. **每次迭代聚焦一个功能**：不要贪多，确保完成质量
2. **及时更新文档**：保持 TODOLIST 和进度日志同步
3. **代码可运行**：提交前确保代码没有语法错误
4. **有意义的提交信息**：便于追溯历史
